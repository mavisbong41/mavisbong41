<h2>HolyShip</h2>

<strong>🏆 Champion · Averis x Monash Hackathon 2026</strong>

<br>
<br>

</div>

My strongest build so far: a shipping-document verification workflow that starts from incoming email and ends with evidence-backed SI-BL comparison.

HolyShip classifies requests, validates attachments, identifies shipping documents, extracts critical fields, highlights discrepancies, and sends uncertain cases through human review before re-comparison.
